# 资料服务接口

资料源支持单段 HTTP Range，返回 Content-Range 和内容摘要 ETag。If-Match 可以限定本次范围读取的来源版本，版本不符返回 412，越界返回 416。该行为只负责传输，不替接收应用决定领域对象是否完整。

Flux 的 sparse=2 表示 PREV，Quality 的 sparse=1 表示 PAD，Epoch 无稀疏。预览只读目录，尚未把物理记录、虚拟值和时间依据组织成观测收件。

真实 NASA CDF3 单文件由 cdflib 生成且反读确认。Flux 物理记录在 0 和 3，使用 PREV；Quality 同样位置使用 PAD；两者依赖单独时间变量。CDF 不等于 NetCDF，记录目录和数据表示有独立结构。来源原件不需要 Python 运行时，项目全部使用 Node.js。

本地服务的资料入口为 `/files/space.cdf`。`fixtures/ordinary.json` 记录当前可预览的资料；`fixtures/transition.json` 保存资料源连续两个发布日期。调用 `POST /control` 并传入 `{"action":"advance"}` 推进发布日期，`inspect` 返回实际请求记录，`reset` 恢复本地源；控制入口不属于远端标准协议。来源分段、延迟和断连均可用场景条目的 `chunks`、`delayMs`、`disconnect` 配置，不需要依赖实际网络故障。

原件目录采用内容摘要寻址，接收凭据独立记录来源、媒体类型和预览结果。单份资料接收不表示来源范围已经读完，也不推断缺失资料的业务含义。
